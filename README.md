# ETF 포트폴리오 계산기 (자동 가격 조회 버전)

국내 상장 ETF의 **전 영업일 종가를 자동으로 가져오는** 포트폴리오 백테스트 / 리밸런싱 계산기입니다.
가격 데이터는 금융위원회가 공공데이터포털을 통해 제공하는 "주식시세정보" 공식 API를 씁니다.

> 이 API는 실시간이 아니라 **영업일 기준 하루 뒤 오후 1시 이후**에 갱신됩니다.
> 즉 오늘 접속해도 최신값은 "어제(또는 가장 최근 영업일) 종가"입니다.

---

## 1. 공공데이터포털 API 키 발급 (무료, 5분)

1. https://www.data.go.kr 회원가입 / 로그인
2. 검색창에 **"금융위원회 주식시세정보"** 검색
3. 해당 오픈API 페이지에서 **활용신청** 클릭 (개발계정은 보통 즉시 자동승인)
4. 승인 후 **마이페이지 > 데이터활용 > Open API 활용신청 현황**에서
   해당 API의 **일반 인증키 (Decoding)** 값을 복사해둡니다.

## 2. Vercel에 배포 (무료)

가장 쉬운 방법은 Vercel CLI를 쓰는 것입니다.

```bash
npm i -g vercel
cd etf-portfolio-planner   # 이 폴더로 이동
vercel
```

안내에 따라 진행하면 배포됩니다 (계정 없으면 무료 가입 화면이 뜹니다).

배포가 끝나면 Vercel 대시보드에서:

1. 방금 만든 프로젝트 선택
2. **Settings > Environment Variables**
3. Key: `DATA_GO_KR_KEY`, Value: 1단계에서 복사한 인증키 붙여넣기
4. 저장 후 **Deployments 탭에서 재배포 (Redeploy)**

이제 배포된 주소(예: `https://etf-portfolio-planner.vercel.app`)로 접속하면
"가격 데이터" 탭에서 종목 티커 옆 **자동 조회** 버튼으로 최근 종가와 과거 가격을 바로 가져올 수 있습니다.

GitHub를 쓰신다면: 이 폴더를 GitHub 저장소로 만들고 Vercel 대시보드 > New Project > 해당 저장소 Import
해도 동일하게 동작합니다 (환경변수 설정은 동일).


## 4. 주의할 점

- 국내(코스피/코스닥) 상장 종목만 지원됩니다. 해외 상장 ETF는 이 API로 조회되지 않습니다.
- 무료 개발계정은 일일 호출 한도가 있습니다(기본 트래픽 제한). 개인 사용 목적이면 충분합니다.
- API 응답이 실시간 시세가 아니므로, 장중 매매 판단에는 증권사 앱의 현재가를 함께 확인하세요.
- `DATA_GO_KR_KEY`는 서버(Vercel 환경변수)에만 저장되고 브라우저에는 노출되지 않습니다.
